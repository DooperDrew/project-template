# Project Template

A spec-first, agent-ready template repository bootstrapped with the **Project Kickstart** methodology.

## What's Included
- `AGENTS.md`: Operating guidelines, complexity tiers, verification gate, and sole committer protocol.
- `docs/01-vision.md`: Vision, problem statement, principles, and non-goals.
- `docs/02-requirements.md`: MoSCoW functional requirements and quantitative performance budgets.
- `docs/03-architecture.md`: Component models, process boundaries, and technical designs.
- `docs/04-ux.md`: User flows, visual keyboard/app layouts, and entry points.
- `docs/05-roadmap.md`: Sized milestone roadmap with parallelization markings (`⇉`).
- `docs/06-qa-and-validation.md`: Verification matrices and empirical testing guidelines.
- `docs/decisions/0000-template.md`: Architecture Decision Record (ADR) skeleton.
- `docs/lessons-learned.md`: Living record of friction points and rules adopted.
- `docs/model-fallback-log.md`: Audit tracking for downgraded model runs.
- `docs/release-methodology.md`: Semantic versioning, packaging, and release checklists.
- `.github/`: Issue templates, PR template, and instructions for GitHub Copilot.

## Usage
1. Use this repository as a template on GitHub or clone it into a fresh workspace.
2. In your initial conversation with an Antigravity agent, run the `/project-kickstart` skill or state:
   > *"Start project definition using the templates in this repository."*
3. Complete the discovery interview, review the generated specifications, and begin building milestone by milestone!
